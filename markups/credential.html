STRIPE_LIVE_KEY

Live payments · added by Maya Chen, 14 Aug
Human-gated. This value is wrapped by a key that only exists in your browser when your passkey unlocks it. Lepidy's servers hold ciphertext they can't open — so nothing is released while you're asleep, and there's no operator who could read it.
How it can reach an agent
Injected — the default
The agent runs lepidy run --with STRIPE_LIVE_KEY -- … and sees only the command's output. The value exists in one child process and nowhere else.
Proxied
Lepidy attaches the key to requests you allow, and returns the response. The value never leaves our servers. Allowed hosts: api.stripe.com
Revealed — off
Hands the plaintext to the agent. That means it's sent to your model provider and written into a transcript file on disk. Off, and it should stay off.
A one-time release you start, for the case injection can't cover. It doesn't change the setting above.
