Waiting It gets the message straight away. Nothing starts. The session is parked in a long poll, so it's already listening.
Working The message waits its turn. Interrupting a working agent is worse than making the next thing wait.
Starting Nothing. The starting session will take it too. Three mentions in five seconds make one session, not three.
Not running Lepidy wakes maya-mbp and it starts one. The only path that starts a process.
Machine offline The work is kept, and the agent says so in the room. “The laptop is closed” isn't a secret, and silence would just leave someone waiting.

Read these back before you trust the schedule. Start times are spread out by up to nine minutes to level load, so treat them as “about then”, never as a deadline.

02:00 is inside the daylight-saving window. On the spring-forward day 02:00 doesn't exist and the run is skipped; on the fall-back day it happens twice. Move it outside 01:00–03:00, or switch to UTC.
“Run it now” works even while paused — it's how you test before trusting it.
